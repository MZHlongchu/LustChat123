## ✨ 此分叉的功能

除了 RikkaHub 中沒有但在 [Cocolalilal 的 LastChat](https://github.com/Cocolalilal/LastChat) 和 [54xzh 的 LastChat Plus](https://github.com/54xzh/LastChat) 中可用的功能外，此分叉還添加了：

- <img src="app/src/main/assets/icons/fal-color.svg" width="16" height="16"> **fal.ai 支援**
- <img src="app/src/main/assets/icons/claude-color.svg" width="16" height="16"> **Anthropic Claude 提示詞快取 (Prompt Caching) 支援**
- 🛡️ **訊息混淆** — 西里爾字母↔拉丁字母，隱形字元，同形字
- 🔇 **隱藏 TTS 按鈕選項**
- 👆 **聊天預覽中滑動刪除訊息**
- 🐛 **錯誤修復**
  - 助手設定中的滑桿無法移動
  - 斜體文字在不支援斜體的字型上無法渲染
  - ~~在助手設定中輸入時輸入框延遲~~ *(尚未實作)*
  - ~~某些圖像裁剪不正確~~ *(無關緊要，LastChat 不使用 UCrop)*
