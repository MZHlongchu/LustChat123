## ✨ 此分叉的功能

除了 RikkaHub 中没有但在 [Cocolalilal 的 LastChat](https://github.com/Cocolalilal/LastChat) 和 [54xzh 的 LastChat Plus](https://github.com/54xzh/LastChat) 中可用的功能外，此分叉还添加了：

- <img src="app/src/main/assets/icons/fal-color.svg" width="16" height="16"> **fal.ai 支持**
- <img src="app/src/main/assets/icons/claude-color.svg" width="16" height="16"> **Anthropic Claude 提示词缓存 (Prompt Caching) 支持**
- 🛡️ **消息混淆** — 西里尔字母↔拉丁字母，隐形字符，同形字
- 🔇 **隐藏 TTS 按钮选项**
- 👆 **聊天预览中滑动删除消息**
- 🐛 **错误修复**
  - 助手设置中的滑块无法移动
  - 斜体文本在不支持斜体的字体上无法渲染
  - ~~在助手设置中输入时输入框滞后~~ *(尚未实现)*
  - ~~某些图像裁剪不正确~~ *(无关紧要，LastChat 不使用 UCrop)*
