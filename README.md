## ✨ Features in this Fork

Aside from features not present in RikkaHub but available in [Cocolalilal's LastChat](https://github.com/Cocolalilal/LastChat) and [54xzh's LastChat Plus](https://github.com/54xzh/LastChat), this fork adds:

- <img src="app/src/main/assets/icons/fal-color.svg" width="16" height="16"> **fal.ai support**
- <img src="app/src/main/assets/icons/claude-color.svg" width="16" height="16"> **Anthropic Claude prompt caching support**
- 🛡️ **Message obfuscation** — Cyrillic↔Latin, invisible chars, homoglyphs
- 🔇 **Hide TTS button option**
- 👆 **Swipe to delete messages in chat preview**
- 🐛 **Bug Fixes**
  - Sliders not moving in assistant settings
  - Italic text not rendering on fonts without italic support
  - ~~Input fields lagged while typing in assistant settings~~ *(not implemented yet)*
  - ~~Some images were not cropped properly~~ *(irrelevant, LastChat does not use UCrop)*

*List will be updated*
